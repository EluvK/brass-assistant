# 自博弈修复验证记录

## 目标与当前结论

目标是让自博弈产生经过实战验证的棋力增长，同时解决重复出现的零分对局。**尚未证明整个目标完成**：规则和搜索修复已通过回归，但后续混合对局仍复现策略性的零分；目前没有经过独立对局验证的学习增益。

进一步结果：repair01 第一轮 16 局仍有 1/64 个零分座位，均分 104.97、未过滤任何局。它说明错误清零规则修复后仍存在策略性的经济崩溃风险，不能宣布零分问题已解决。

## 已实现

- 取消永久破产淘汰、强制 Pass 和直接清零；正常欠款仍卖资产偿付、扣除不足部分对应 VP。
- 搜索不再修改停滞计数或使用破产伪终局。只在真实终局使用终局 VP 差。
- 分开记录已完成访问与待返回预约；待返回值不再把负 Q 稀释为 0。
- 实际搜索批大小最多 `max(1, sims // 8)`，低模拟预算也能获得多次反馈。
- 隐藏手牌导致分支不可用时，在当前 simulation 中继续选择其他可执行分支。
- 使用已通过评测的 best 采样；候选 latest 继续学习但不能未经验证接替采样模型。历史池只加入底座和晋升模型。
- 晋升同时要求 arena 达标、对教师评测无零分、平均 VP 不低于 best。
- 开始训练时写出 best；latest 内嵌 champion 和完整参数；续训保留原基准。
- 全局对局编号决定发牌及保留座位；混合局采集所有当前 champion 座位，避免无谓丢弃样本。
- 输出采集座位均分、完整局数、零分座位数、过滤局数；未评估 arena 显示 `--`。竞技胜负使用引擎正式排序，评测拒绝未完成对局。
- 后续启动的 CLI 实验默认将所有自博弈的 canonical 行动记录到 `<ckpt-dir>/games/game-<seed>.json`，包括完整/截断标记、最终分数和排名；不因低分过滤丢失回放。已验证回放逐步重放得到相同终局。repair01 启动早于这一改动，仍需另行采集低分回放。
- 微调起点改为 `lr=1e-4`、1 epoch、温度 0，根噪声仍开启。这些设置是待验证的起点。

## 训练验证

实验目录：`checkpoints/v1/runs/repair01`。原计划从 `b10000.pt` 开始跑 8 iterations，每轮 16 局、64 sims、8 workers、`lr=1e-4`、1 epoch、温度 0、先验候选上限 32、每对手座位教师概率 0.25。每 2 轮进行 16 局 arena 与 16 局 heuristic 评测，评测同为 64 sims。恢复工作时已核实原进程句柄不存在，磁盘仅有 iteration 0；不能把之前“正在训练”的描述作为当前进程仍运行或实验已完成的证据。

成功判据不能仅用 loss 下降或没有晋升：需要检查零分率及实际亏损轨迹，并在独立发牌/座位组验证晋升模型比底座更强。若候选持续无法晋升，需要继续诊断搜索目标质量、Q/V 排序、训练更新与探索策略，不能把冻结 best 当作“进化完成”。

底座的既有 `bench_value_ranking.py` 探针（36 局面、216 heuristic rollout）得到 V 相关性 +0.035±0.082，Q +0.021±0.105，尚不能证明有效的兄弟动作排序。该探针本身使用单次 rollout，且并列排序和时代边界处理还需核查，不能将其用作确定性的数值放行门槛。

## 恢复后的对照

- `bench_value_ranking.py` 已修复并列排名（使用平均秩）、时代边界推进，并排除完全相同特征的重复候选。重新测得 V +0.043±0.079、Q +0.083±0.101，仍没有有力的排序优势证据。
- 新增 `python/bench_selfplay_health.py`：固定发牌与座位，比较 policy / Q 初始化 / 不同探索常数，保存全部 canonical 回放与逐局分数；支持教师对战、全网络自博弈和混合教师自博弈。输出目录必须为空，防止覆盖对照结果。
- `logs/health-calibration`，seed64–67，每组 4 局：policy 103.75，Q/c=0.25 为 114.5，V/c=0.25 为 109.75，V/c=1 为 94，V/c=2.5 为 105。各组都没有零分；样本少且有搜索随机性，不支持直接宣布关闭 Q 或增大 c 更优。
- `logs/health-selfplay-noisy`，seed0–7，64 sims、Q/c=0.25、完整根噪声、全网络自博弈：32 个座位均分 107.44、最低 74、零分 0/32。
- 同一初始局面的 8 次 64-sim 搜索计时，单 CPU 线程约 6.20 秒，GPU 约 0.70 秒。因此后续长程对照优先使用单 actor GPU 路径（`--workers 1 --device cuda`）；这是本机测试，不是对所有硬件的性能保证。

## 混合对局的剩余失败与价值校准

- `logs/health-mixed-noisy`：底座、seed0–15、64 sims、Q/c=0.25、根噪声开启，每个非保留座位以 0.25 概率使用 heuristic。64 个座位均分 103.95，零分 1/64。seed0 为 `[105,98,0,94]`；零分的 player2 是模型座位。
- 已逐手重放 `q025/game-0.json` 并验证终局一致：player2 连续贷款、开发及建设未翻面的产业，运河末收入降至 −9、现金接近耗尽；铁路期无法继续贷款，变卖资产和欠款扣 VP，最终 0 分。这是经济策略失败，不能通过过滤失败样本、抹平分数或修改贷款合法性来解决。
- `python/calibrate_value.py` 用这 16 局的 1984 个状态训练 6 epochs，只更新 value/Q/winner/economy 输出头；保存前逐参数验证 policy 和共享骨干完全未变。它加强了对训练集中已崩溃局面的负面估计，但这不能证明选步改善。
- 独立 seed128–143 的混合对局对照均已完成：

| 模型 | 全桌平均 VP | 零分座位 | 结果目录 |
| --- | ---: | ---: | --- |
| b10000 底座 | 104.9375 | 3/64 | `logs/health-holdout-base` |
| 只校准输出头 | 104.0625 | 2/64 | `logs/health-holdout-value` |

该实验没有证明改善，也未解决零分，不应晋升或作为已验证的默认训练方案。发牌和座位相同，但 Rust 搜索仍有独立随机性；小样本胜局数量不能作棋力结论。下一步隔离根噪声和搜索相对策略直出的影响，再决定如何改进学习目标。

## 根噪声对照与关键决策探针

`logs/health-holdout-no-noise` 已完成 seed128–143、每组 16 局的混合对照：

| 底座选步方式 | 全桌平均 VP | 零分座位 |
| --- | ---: | ---: |
| MCTS，根噪声开启（此前对照） | 104.9375 | 3/64 |
| MCTS，根噪声关闭 | 101.453125 | 3/64 |
| 策略网络直接选步 | 106.359375 | 2/64 |

关闭噪声、甚至不执行 MCTS 都能复现零分，说明底座策略本身存在经济崩溃路径。不能据此用关闭根噪声或单纯增加搜索深度作为解决方案。这些是全桌指标（包括教师座位），不是候选模型对固定对手的棋力增益。

新增 `bench_replay_decisions.py`，对 seed130 的 step7/18/30（零起始）进行候选动作探针；完整数据为 `logs/health-holdout-base/decision-audit-130.json`。每个局面采样 4 个隐藏世界，各动作在相同世界中执行，然后全部座位用 heuristic 走到终局：

- step7：原陶器建设先验 0.738，搜索仍选择它；续局平均 VP 80.0，教师的开发动作平均 121.75。提示在危机早期存在更好的候选，网络先验与短程价值估计未能识别。
- step18：原贷款续局平均 82.25，教师建议开发反而只有 66.25，并有一次零分。不能把教师选择视为每个失败局面的正确标签。
- step30：原第三次贷款 Q 约 −0.240，续局平均实际效用 −1.451，4 次中 3 次零分；其他多个候选也已很差。只在收入降至 −9 时干预可能太晚。

续局行为与实际混合对手不同，4 个世界不足以精确估计动作价值；该探针用来确定诊断方向，不是晋升评测。

实验 `value-distillation`：仍只使用 seed0–15 的 1984 个状态，更新共享骨干及所有输出头，但用训练前完整策略分布作为固定 CE/KL 约束；价值和 Q 仍学习实际终局结果。6 epochs 已完成，未晋升。相比只训练输出头，它允许价值表征更新，但不保证策略完全不变。

独立 seed128–143 的 16 局混合验证已全部完成（`logs/health-holdout-distill`）：全桌平均 VP **107.875**，零分 **1/64**，仍为 seed130 的 player0。相对底座同组的 104.9375 与 3/64 有改善迹象，但没有解决零分；全桌指标及小样本不能替代固定对手的棋力比较。

同一组独立回放上的逐状态评估（`replay-errors.json`，1984 个状态）：V 的均方误差 0.23550 → 0.22540，实际执行动作 Q 的误差 0.18487 → 0.13920；策略平均 KL 为 0.01836。Q 改善主要出现在铁路阶段（0.14565 → 0.08286），运河阶段较小（0.22670 → 0.19929）。这说明价值学习并非仅拟合训练集，但仍不足以避免危机早期的错误。需要继续验证固定对手棋力并改善早期动作排序，不能把回放误差下降作为进化完成。
