# 商人特征补全与空间地理嵌入实现方案 (F_MERCHANT 6 -> 15)

### 一、方案目标
解决商人（Merchant）Token 当前在模型中的“信息孤岛”问题，消除因 1,320 种地图开局随机性对神经网络造成的表征学习阻力：
1. **注入空间地理坐标**：为 9 个商人 Token 注入与地图 Cell / Link 共享的 `location_embed`，让 Attention 能天然计算空间亲和度；
2. **显式补全商人奖励（Bonus）**：编码 4 维归一化标量（VP / 现金 / 收入 / 免费研发），强化开局经济与科技规划大局观；
3. **补齐网络连通与图距离**：编码该商人是否在各玩家网络内（4 维相对座位）以及距当前行动玩家网络的拓扑跳数距离（1 维），让价值网络秒懂“卖货路径成本”。

---

### 二、具体特征设计规范 (F_MERCHANT: 6 -> 15)

每个商人槽位（共 9 个）的 15 维特征分布如下：

| 索引 / 偏移 | 特征名称 | 维度 | 规范与缩放 | 说明 |
| :--- | :--- | :---: | :--- | :--- |
| `0..5` | `MERCHANT_BUY` | 5 | One-hot | Blank(0), Any(1), Cotton(2), Manufacturer(3), Pottery(4) |
| `5` | `MERCHANT_BEER` | 1 | 0.0 或 1.0 | 该槽位当前是否有未使用的啤酒 |
| `6..10` | `MERCHANT_BONUS` | 4 | 稀疏归一化标量 | `[vp/10.0, money/20.0, income/10.0, develop/2.0]`<br>• Shrewsbury: `[0.4, 0, 0, 0]`<br>• Gloucester: `[0, 0, 0, 0.5]`<br>• Oxford: `[0, 0, 0.2, 0]`<br>• Warrington: `[0, 0.25, 0, 0]`<br>• Nottingham: `[0.3, 0, 0, 0]` |
| `10..14` | `MERCHANT_IN_NET`| 4 | 0.0 或 1.0 | 相对视角 4 玩家网络归属（0 为当前行动玩家，1..3 为顺位对手） |
| `14` | `MERCHANT_DIST` | 1 | $[0.0, 1.0]$ | 距离当前行动玩家网络的最短链路步数 `/ 6.0`（0.0 表示已连通） |

### 三、涉及文件与修改清单

#### 1. Rust 引擎特征编码 (`engine/src/bridge/encode.rs`)
- 更新 Schema 版本号：`STATE_TOKEN_SCHEMA_VERSION = 2`（安全提示升级，避免误读旧 checkpoint）；
- 扩展常量：`F_MERCHANT = 15`，定义 `MERCHANT_BONUS = 6`、`MERCHANT_IN_NET = 10`、`MERCHANT_DIST = 14` 及其 Scale 常量；
- 新增公共导出函数 `merchant_locations() -> Vec<usize>`（输出 9 个槽位对应的 27 地点 ID 列表）；
- 修改 `merchants_vec` 签名及逻辑，传入 `pid` 与 `net_masks`，复用 `distance_from_network` 计算商人距离与网络掩码；
- 更新 `state_tokens` 调用点及模块单元测试。

#### 2. PyO3 桥接层 (`engine/src/bridge/pymod.rs`)
- 导出新增常量与函数：`MERCHANT_BONUS`、`MERCHANT_IN_NET`、`MERCHANT_DIST` 以及 `MERCHANT_LOCATIONS = encode::merchant_locations()`。

#### 3. Python 类型提示 (`python/brass_ai/_engine.pyi`)
- 声明新增的常量 `MERCHANT_BONUS`、`MERCHANT_IN_NET`、`MERCHANT_DIST`、`MERCHANT_LOCATIONS: list[int]`。

#### 4. Python 神经网络模型 (`python/brass_ai/net.py`)
- 在 `PolicyValueNet.__init__` 中注册 buffer：
  ```python
  self.register_buffer(
      "merchant_locations",
      torch.tensor(be.MERCHANT_LOCATIONS, dtype=torch.long),
  )
  ```
- 在 `PolicyValueNet.encode_state` 中注入空间嵌入：
  ```python
  elif name == "merchants":
      vec = vec + self.location_embed(self.merchant_locations).unsqueeze(0)
  ```

#### 5. 技术文档同步 (`docs/ai-action-encoding.md`)
- 更新 §2.3 Merchant token 规范描述，记录 15 维结构定义与物理含义。
