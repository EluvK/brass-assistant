## 1. 下一步焦点（明天开工）

**Step A：从 `best_masked.pt` 正式跑多进程自对弈，打通 AlphaZero 闭环。**

核心假设：masked-loss 修复后 policy 变强（贪心 7→50 VP），之前观察到的「自对弈 8 轮塌缩到 2.6 VP」（根因是弱 value 污染 + 弱 policy）可能不再复现。这是本会话最大的待验证事项。

执行方式（已有基建，无需新代码）：
```bash
# repo 根目录
PYTHONPATH=src/ai ./src/engine/.venv/Scripts/python.exe src/ai/train_mp.py \
  --ckpt checkpoints/best_masked.pt \
  --iters 10 --workers 8 --games_per_worker 2 --sims 200 \
  --lr 5e-5 --c_puct 2.5 --temp 0.7 --gate \
  --out checkpoints/selfplay_mp.pt
```

1. 每 3 轮评估用 6-8 局、sims=60，MCTS vs 启发式 **VP 维持 ≥70 且不塌缩**（`--gate` 保证不倒退）。
2. 若 VP 稳定/上升，说明闭环打通；若又塌缩，需先查 value 训练（见 §5 遗留项）。

## 4. 本会话关键结论（已写入 docs/architecture.md，此处仅摘要）

1. **masked-loss 是弱 policy 的根因**：策略表 1316 槽中 ~703 个 double-rail 幽灵槽进 softmax 分母（初始 ~53% 质量），网络浪费梯度压制它们。修复后：贪心 policy 7→50 VP、MCTS vs 启发式 62% 胜率（72.6/65.2）、vs 2ply 70.8/75.8。**训练侧掩码，推理侧 `_masked_softmax` 一直是对的**。
2. **自对弈塌缩诊断**：弱 value → 自对弈目标嘈杂 → value 污染 → 负反馈。已加 `--gate` 回退保护。
3. **性能**：子节点惰性物化（5.6→3.3ms/sim，1.7×）、多进程 8 workers（4.7×）、全链路 progress/ETA。
4. **评估纪律教训**：2 局评估 VP 波动 ±15，曾把噪声误读成提升（Step-0 的 59 用 8 局重测仅 30）。**评估必须 ≥6-8 局或滚动平均**。
